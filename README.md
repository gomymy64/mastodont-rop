# Мастодонт РОП

Контроль качества звонков отдела продаж - один экран для нейро-РОПа.

Демо синтетического отдела продаж по курсу заработка на ИИ. Дашборд, карточки менеджеров, расшифровки звонков с разметкой проблемных моментов, AI-инсайты «РОП говорит сегодня».

## Стек

- Чистый HTML + CSS + JS, без сборки
- SVG-графики (donut, radar, line, sparkline) - без библиотек
- Manrope + Archivo Black + JetBrains Mono с Google Fonts
- Бренд - Мастодонт Дизайн (чёрный фон, butter yellow `#F2DB82`)

## Запуск

Открой `index.html` в браузере. Всё.

## Экраны

- `/` - дашборд команды + AI-инсайты
- `/manager/:id` - карточка менеджера + 30-дневный график + список звонков
- `/call/:id` - расшифровка звонка + поскритериальные оценки + рекомендация РОПа
